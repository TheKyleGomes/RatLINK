# Rat:LINK

A 2D game project using Unity 6000.2.2f1 and the Universal 2D template (URP 2D Renderer).

## Open the project

In Unity Hub, choose Add project from disk and select this folder. Open with Unity 6000.2.2f1. Let Unity restore packages and import assets, then open Assets/Scenes/SampleScene.unity.

## Save and back up your work

1. Save scenes and assets in Unity.
2. In GitHub Desktop, add this existing local repository. Review the changed files, write a short description, and commit to main.
3. Click Push origin. A local commit is only backed up on GitHub after the push succeeds.

Assets (including their .meta files), Packages, and ProjectSettings are tracked. Generated caches, builds, and machine-specific settings are excluded. Binary art and audio use Git LFS; install Git LFS before cloning with the command line.

The repository is public. Keep credentials and private files outside it. No open-source license has been selected.

## Restore on another computer

Clone the repository using GitHub Desktop, or run `git lfs install` followed by `git clone https://github.com/TheKyleGomes/RatLINK.git`. Open the cloned folder in Unity Hub with the pinned editor version. Unity recreates its excluded cache folders.

## Additional backup

An initial ZIP snapshot and Git history bundle are provided beside the project folder. Copy these to a separate drive or cloud backup for protection independent of GitHub. These snapshots capture the initial setup; make fresh backups as development progresses.
